# Project Design Governance

For every frontend/UI task, use BOTH skills when available:
- `atmospheric-ui` is the authority for visual art direction: palette behavior, gradients, materiality, typography mood, layouts, cards, buttons, 3D and motion.
- `ui-ux-pro-max` provides UX best practices, accessibility, responsive design, semantic structure, usability, component completeness and QA.

Do not allow UI UX Pro Max's generated palettes, generic style recommendations or templates to replace ATMOSPHERIC UI's art direction. Preserve accessibility, readability and functional quality if a visual rule creates a conflict; find a compatible design solution.

Before implementing a UI, briefly identify the selected palette approach, materials, layout and interaction pattern. Avoid producing the same layout for every project. Respect reduced motion and mobile usability.
